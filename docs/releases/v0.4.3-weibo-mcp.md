## 升级方式

已有业务电脑必须使用 `ArticleOps-upgrade-v0.4.3-<commit>.zip` 原地升级，先运行
`apply_upgrade_windows.ps1 -TargetRoot <目录> -ValidateOnly`。升级器只替换清单内
程序文件，保留业务数据、账号 Profile、历史记录和生产配置。
