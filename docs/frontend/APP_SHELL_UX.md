# ArticleOps 统一应用壳层

## 目标

`/`、`/upload`、`/accounts`、`/task/*`、`/settings/ai`
必须呈现为同一套本地运营工作台。各页面保留自己的业务组件，但跨页时画布、侧边栏、页头、标题和卡片边界不得跳变。

## Design Tokens

- 画布：`#f3f5f9`
- 主表面：`#ffffff`
- 主文字：`#0f172a`
- 次文字：`#526075`
- 品牌蓝：`#2563eb`
- 浅色侧栏：`#ffffff`
- 侧栏悬停：`#f1f5f9`
- 侧栏选中：`rgb(37 99 235 / 10%)`
- 内容最大宽度：`1600px`
- Header 高度：`72px`
- 侧栏宽度：默认 `248px`，可调范围 `216–320px`，折叠后 `80px`
- 卡片圆角：`16px`
- 焦点环：`2px #1d4ed8`，偏移 `2px`

暗色主题继续由 `[data-theme="dark"]` 覆盖；浅色侧栏不会被复用于业务警示卡。

## 组件规则

- 导航分组和导航项点击高度不低于 `44px`。
- 当前导航使用浅蓝背景、蓝色文字和左侧状态条。
- 页面标题使用 `clamp(1.55rem, 2.4vw, 2.05rem)`。
- 卡片统一使用白底、细边框、轻阴影；不使用页面专属的大面积深色装饰块。
- 主按钮、表单控件和图标按钮点击高度不低于 `44px`。
- 首页 KPI 使用语义色顶部边线；数值缺失时继续显示真实缺失态，不制造数据。

## 页面边界

- 共享壳层：`web/templates/base.html`、`design-tokens.css`、`style.css`、`app.js`。
- 创作、账号、AI 设置只覆盖业务组件，不重新定义壳层。
- 所有现有 Jinja、Alpine、DOM ID、`data-*`、API URL 和请求字段保持不变。

## 响应式与无障碍

- 验收宽度：`1440px`、`1024px`、`390px`。
- `992px` 以下侧边栏变为抽屉，支持 Esc 关闭并归还焦点。
- 页面不得产生横向滚动；宽表格只在自身容器内滚动。
- 键盘焦点始终可见；系统设置减少动效时，将过渡时间降至接近零。
- 正文与背景对比度遵循 WCAG AA，状态不能只依赖颜色表达。
