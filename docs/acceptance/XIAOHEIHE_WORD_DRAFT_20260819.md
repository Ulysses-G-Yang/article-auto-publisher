## 根因与修复

失败证据指向两项组合问题：图片处理前把文字全部写完、图片再批量处理，且上传前对正文编辑器执行普通中心点击；在 ProseMirror 重建或插入图片时，中心点击可能把插入点移到正文中段，破坏后续段落。

修复已在提交 `ccb57789924fc02ba1bb2306ee08452114c877c4` 推送；媒体失败进度审计已在提交 `927bc45dfc7336dd92443dc8cac7c0708a7e559f` 推送：

1. 按冻结内容块原始顺序交错写入文字与图片。
2. 通过当前可见正文编辑器的 `focus + Selection/Range.collapse(false)` 将插入点置于末尾，不再用正文中心点击。
3. 每张图片后重新定位编辑器并校验已写文字前缀；首个缺失/乱序立即停止后续图片，并保留媒体状态与错误脱敏语义。
4. 后续失败可从账号活动读取仅含数量和状态的脱敏 `MEDIA_PROGRESS` 记录，不包含路径、Token 或正文。

修复后的真实平台重验收尚未进行；在新的人工授权前不得据此晋级为稳定可用。
